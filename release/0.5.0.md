## Breaking Changes (from 0.4)

1. `ZaiClient` replaces per-request API keys — all constructors drop the `key` parameter
2. `send_via(&client)` replaces `send()` — credentials/transport come from `ZaiClient`
3. `with_base_url`/`with_endpoint_config`/`with_http_config` removed — use `ZaiClient::builder().endpoint()`
4. Agent API rewritten — `/paas/v4/agents` CRUD removed, Agent v1 contract implemented
5. Async chat stream removed — task-submission endpoint does not accept `stream`
6. `toolkits` feature added; `tool-validation` is now a compatibility alias

See [docs/MIGRATING-0.5.md](../docs/MIGRATING-0.5.md) for the full migration guide.
